# Assets

Generated media for this project (Higgsfield videos, Nano Banana / Flux images, etc.).

## Convention

- **Finals live here** (and in subfolders by type if useful, e.g. `images/`, `video/`). Commit these — they're the picks we actually use.
- **Drafts live in `drafts/`** — throwaway iterations and re-rolls. This folder is **gitignored** (see repo `.gitignore`), so it never bloats the AIOS repo. Anything you want to keep, move up into `assets/`.

## Naming

`YYYY-MM-DD_subject_shot.ext` — e.g. `2026-06-14_calle-falsa-123_drone-reveal.mp4`, `2026-06-14_kitchen_orbit.mp4`. Keeps clips sortable and traceable to the listing.

See [references/higgsfield-playbook.md](../../../references/higgsfield-playbook.md) for the generation workflow.
