Banderas sobre tus números (corroboración)

  • WhatsApp "retención $15": Meta Cloud API no cobra fee mensual de plataforma. Con el modelo por-mensaje, las conversaciones de servicio (cliente escribe, vos respondés dentro de 24h) son gratis. Tu "$0 solo respuestas" está bien. El $15 solo existe si vas por un BSP (Twilio, 360dialog) en vez de Cloud API directo. Confirmá cuál usás.
  • Claude $100: si es tu suscripción mensual que usás en TODOS tus proyectos, es overhead tuyo de negocio, no costo de este proyecto. Cargarlo entero acá te infla el costo y te esconde el margen real. Atribuí una fracción o sacalo.
  • 4 vCPU es holgado para una sola imprenta (~900 conv/mes). 2/8 (KVM 2) alcanzaría. Voy a 4/8 igual porque en Hetzner cuesta casi lo mismo y te da aire para Chatwoot + n8n + Postgres + Redis juntos.
  • Dominio es costo anual recurrente de TG (~$10/año), no one-time de desarrollo.
  • Pico de tokens: en pass-through es costo de TG, no tuyo. Nunca te comas tokens en un pago único. Defensas que ya tenés: OpenRouter (cambiás de modelo), max_tokens topeado, RAG optimizado. Sumá topes de gasto en la cuenta de TG.
  • Decisión abierta: pass-through vs managed. Para este cliente (quiere ser dueño y no depender de vos) → pass-through. El managed le contradice lo que pidió.
